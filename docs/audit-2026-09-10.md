Three independent Astra agents reviewed UX/client architecture, data integrity, and API/release
safeguards; changes were written in separate worktrees and integrated by one lead.

## Library and architecture decisions

Reuse TanStack Query 5, Expo Router, Zod, Better Auth, Drizzle, CVA and React Native primitives.
Do not add a second state store, ORM, router or component framework. Axios 1.20.0 supplies a maintained
cross-platform HTTP transport and timeout/cancellation handling. The existing API client retains
typed request/response validation, credential ownership and error translation. Financial mutations
are never automatically retried. Cancellation after a write begins remains an uncertain result.

`@types/react-dom` 19.2.3 is development-only for real React Native Web rendering tests and matches
the installed React 19.2 types. No provider-specific client SDK was added for hosting or Neon.
See [ADR 0017](adrs/0017-portable-postgres-and-hosting.md) for the portable deployment decision.

Sources reviewed: [Axios cancellation](https://axios-http.com/docs/cancellation),
[TanStack native focus/network](https://tanstack.com/query/latest/docs/framework/react/react-native),
and [PostgreSQL atomic UPSERT](https://www.postgresql.org/docs/current/sql-insert.html).
Recheck compatibility and advisories on dependency updates; the committed lockfile and actual tests
establish the installed state.
